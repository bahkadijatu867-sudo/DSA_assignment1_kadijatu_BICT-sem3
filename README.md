# DCOMP320 - Stacks Implementation

Stack-based evaluator for mathematical expressions.
Reads expressions from `input.txt`, evaluates each one with two stacks
(values and operators), and writes the results to `output.txt`.

## Files
| File | Description |
|------|-------------|
| `expression_evaluator.py` | Python source code (Stack class, evaluator, file I/O) |
| `input.txt` | Sample input used for testing |
| `output.txt` | Output generated by the program |
| `README.md` | This file |

## How to run
1. Install Python 3 (no extra libraries are needed).
2. Put `expression_evaluator.py` and `input.txt` in the same folder.
3. Open a terminal in that folder and run:
   ```
   python expression_evaluator.py
   ```
4. The program prints `Done. Results written to output.txt` and creates `output.txt`.

## Input format
- One expression per line.
- Expressions are separated by a line made only of dashes, e.g. `----------------`.

```
3 + 5 * 2
----------------
(8 / 4) + 7 * 2
----------------
10 - (2 + 3) * 4
```

## Output format
Each expression is replaced by its result; separator lines are copied unchanged.

```
13
----------------
16
----------------
-10
```

## Supported features
Operators `+ - * /`, parentheses (nested), operator precedence, left
associativity, unary minus (e.g. `-5 + 3`), multi-digit and decimal numbers.

## Assumptions and limitations
- A separator is a line containing only dashes.
- Whole-number results are printed without a decimal point (`13`, not `13.0`).
- Invalid lines do not stop the program; an error message is written instead:
  `ERROR: Division by zero.`, `ERROR: Mismatched parentheses.`,
  `ERROR: Unknown character.`
- Exponents, modulus, functions and variables are not supported.
- Note: the sample output in the assignment brief shows `17` for
  `(8 / 4) + 7 * 2`; the correct value is `16`.____________
